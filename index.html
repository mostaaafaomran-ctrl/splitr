Splitr

Split the project. Skip the fights.

Paste the assignment, add your teammates, pick the deadline. Splitr hands out the tasks fairly and gives each person their own dates.

Each line becomes a task. If you paste a paragraph, each sentence becomes one.
How the split works
  1. Longer tasks count as heavier, so the load stays even.
  2. Each task goes to the person with the lightest load so far.
  3. Deadlines are spread between start and final date. The last day is kept for merging and review.
  4. Copy the result and drop it in the group chat.

Everything runs in your browser. Nothing is uploaded or saved.
